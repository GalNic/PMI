# PMI · Plataforma de Mantenimiento Industrial

Prototipo de demostración con el asistente R.A.U.L., manuales en español, saber de planta y repuestos.

- `index.html`: la plataforma (funciona en celular y computadora, sin iniciar sesión).
- `qr.html`: muestra el código QR que lleva a la plataforma, para proyectar en la exposición.

Los datos son de ejemplo.
